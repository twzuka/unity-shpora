Глава 01

Движок и первый проект

Что такое игровой движок, зачем нужен Unity Hub и как создать проект, чтобы потом ничего не потерять.

Что такое игровой движок

Раньше графику, звук и управление для каждой игры писали с нуля. Игровой движок собирает эти части в один «каркас», который можно использовать снова и снова:

  • графический движок рисует картинку;
  • звуковой отвечает за звук;
  • физический считает столкновения и падения;
  • скриптовый выполняет код игры.

Unity — бесплатный движок с удобным визуальным редактором. На нём делают 2D- и 3D-игры любых жанров, а для обучения есть много бесплатных материалов.

Подготовь папку для проектов

Каждый проект Unity — это отдельная папка с сотнями файлов. Чтобы проекты не потерялись, держи их в одном месте:

  1. Выбери диск, где свободно не меньше 50 ГБ.
  2. Создай на нём папку UnityProjects.
  3. Все новые проекты сохраняй туда.

Создать новый проект в Unity Hub

Unity Hub — программа-«пульт»: через неё устанавливают версии Unity, создают и открывают проекты.

  1. Открой Unity Hub → вкладка Projects → New project.
  2. Выбери шаблон 3D (Core).
  3. Впиши имя проекта латиницей и укажи путь к папке UnityProjects.
  4. Нажми Create project и дождись, пока откроется редактор.
СоветОткрывай проекты тоже через Unity Hub: он сам запустит нужную версию редактора.

Коротко

Движок — готовый каркас для игры. Проекты создаются и открываются через Unity Hub и лежат в одной папке UnityProjects.

Глава 02

Интерфейс редактора

Пять главных окон Unity и правила работы с файлами проекта.

Пять главных окон

Что есть в новой сцене

  • Main Camera — камера, через которую игрок видит мир.
  • Directional Light — «солнце», которое освещает сцену.

Создать папку в окне Project

  1. Щёлкни по папке Assets.
  2. ПКМ по пустому месту → CreateFolder.
  3. Впиши имя, например Levels.
  4. Перетащи туда папку Scenes.
ВажноФайлы из Assets двигай, переименовывай и удаляй только в окне Project. Если делать это в проводнике, Unity потеряет связи, и со сцены могут пропасть объекты.

Как разложить файлы

Assets/
├─ Levels/
│  ├─ Scenes/       ← сцены
│  └─ Prefabs/      ← префабы
├─ Art/
│  ├─ Materials/    ← материалы
│  └─ Textures/     ← текстуры
└─ ThirdParty/      ← всё скачанное

Как называть

  • Объекты на сцене — по-английски: Tree, Tower, Wall_1.
  • Папки и ассеты — в стиле PascalCase: слова слитно, каждое с большой буквы. Например, StoneWall, ThirdParty.

Коротко

Scene — где строим, Game — что видит игрок, Hierarchy — что стоит на сцене, Inspector — настройки выбранного, Project — файлы. Файлы трогаем только внутри Unity.

Глава 03

Объекты и компоненты

Из чего состоит любой объект в Unity и как создавать простые 3D-фигуры.

Объект — это контейнер

Сам по себе игровой объект пустой, как котелок. Компоненты — ингредиенты: что положишь, то и получится. Добавил компонент Light — объект светит. Убрал — перестал светить.

У каждого объекта есть Transform: положение, поворот и размер. Его удалить нельзя.

  • Убрать компонент: три точки ⋮ справа от его названия → Remove Component.
  • Добавить: кнопка Add Component внизу Inspector.
  • Передумал: Ctrl+Z.

Как это выглядит в Inspector

Ассет или игровой объект?

Где живётПример
Ассетфайл в папке Assets, виден в Projectсцена, материал, текстура, префаб
Игровой объектстоит на сцене, виден в HierarchyMain Camera, куб на сцене

Создать 3D-фигуру (примитив)

ПримитивЧто из него получится

Sphereмячи, планеты, крона дерева

Переименовать, удалить, сохранить

  • Переименовать: объект в Hierarchy → ПКМ → Rename → новое имя по-английски.
  • Удалить: ПКМ → Delete. Несколько объектов выделяй с Ctrl.
  • Сохранить сцену: FileSave или Ctrl+S. Сохраняй почаще.

Коротко

Объект = контейнер + компоненты. Transform есть всегда. Простые фигуры берём из меню GameObject → 3D Object.

Глава 04

Инструменты и навигация

Как двигать, вращать и масштабировать объекты и как не потеряться в сцене.

Панель инструментов

  • W — двигать, E — вращать, R — менять размер.
  • Оси раскрашены: X — красная, Y — зелёная (вверх), Z — синяя. Тяни за ось нужного цвета.
  • Чтобы увеличить объект сразу во все стороны, выбери R и тяни за кубик в центре: вверх — больше, вниз — меньше.
  • Для точности впиши числа в Position, Rotation, Scale в Inspector.

Режим полёта по сцене

  1. Зажми ПКМ в окне Scene.
  2. Лети: WASD — вперёд, влево, назад, вправо.
  3. Q — вниз, E — вверх.
Потерялся?Выбери объект в Hierarchy и нажми F — камера подлетит к нему.

Гизмо сцены

Щёлкни по оси, чтобы посмотреть с этой стороны: по зелёной — вид сверху, по красной и синей — виды сбоку. Название вида подписано под значком.

Копировать и выделять

  • Дублировать: Ctrl+D или ПКМ → Duplicate. Копия встаёт ровно на место оригинала — сдвинь её.
  • Выделить несколько: Shift+клик. Их можно двигать и вращать вместе.
  • Снять выделение: клик по пустому месту.
  • Прилепить к вершине: зажми V, возьми объект за угол и подтащи к углу другого — они сомкнутся.

Коротко

W, E, R — двигать, вращать, масштабировать. ПКМ + WASD — полёт. F — найти объект.

Глава 05

Иерархия и группировка

Как собрать сложный объект из частей, чтобы он двигался целиком.

Зачем группировать

Дерево из ствола и кроны — это два отдельных объекта. Если нужно десять деревьев, в Hierarchy быстро начнётся путаница. Решение — сложить части в общий пустой объект-контейнер.

Как сгруппировать

  1. Выдели все части объекта в Hierarchy.
  2. ПКМ → Create Empty Parent.
  3. Назови контейнер, например Tree.
Почему не Create EmptyПустой объект, созданный отдельно, появится не в центре частей. Потом такой объект будет вставать на сцену со смещением.

Как ведут себя родитель и дети

  • Двигаешь, вращаешь или растягиваешь родителя — дети повторяют за ним.
  • Координаты детей считаются от центра родителя, а не от центра сцены.
  • Поэтому, когда двигаешь всю группу, числа в Transform меняются только у родителя.

Коротко

Выделить части → Create Empty Parent → дать имя. Родитель управляет детьми.

Глава 06

Префабы

Шаблоны объектов: меняешь один раз — меняются все копии.

Префаб и экземпляры

Префаб — это шаблон объекта, сохранённый как файл. Экземпляры — его копии на сцене. В отличие от обычных дубликатов, экземпляры связаны с префабом: поменял префаб — поменялись все.

Ещё плюсы: префаб можно использовать в других сценах, и он останется на диске, даже если ты забыл сохранить сцену.

Создать префаб и поставить экземпляр

  1. Создай папку Levels/Prefabs.
  2. Перетащи объект из Hierarchy в эту папку в окне Project. Готово — это префаб.
  3. Объект на сцене стал голубым: голубым отмечаются все экземпляры.
  4. Новый экземпляр — перетащи префаб из Project в окно Scene.

Изменить префаб

Prefab Mode — префаб открывается отдельно от сцены:

  1. Выбери префаб в Project.
  2. Open вверху Inspector или двойной клик.

Prefab in Context — префаб открывается среди других объектов сцены. Удобно, когда нужно подогнать его под соседей, например стулья под стол:

  1. Выбери экземпляр в Hierarchy.
  2. Open вверху Inspector.

Выход в обоих случаях — стрелка в левом верхнем углу Hierarchy. Изменения сразу попадут во все экземпляры.

Изменил экземпляр — как применить ко всем

  1. Выбери изменённый экземпляр.
  2. В Inspector нажми Overrides.
  3. Apply All — изменения уйдут в префаб.

Новый префаб на основе старого

  1. Перетащи экземпляр в окно Project.
  2. Выбери Original Prefab.

Получится новый независимый префаб: например, дерево другой формы на основе старого.

Удалить префаб

  1. Префаб в Project → ПКМ → Delete.
  2. Delete and unpack.

Файл удалится, а экземпляры на сцене станут обычными объектами.

ВажноОтменить это нельзя.

Коротко

Объект → в Project = префаб. Префаб → в Scene = экземпляр. Правки: Prefab Mode, Prefab in Context или Overrides → Apply All.

Глава 07

Как устроена 3D-графика

Почему 3D-мир на плоском экране выглядит объёмным и из чего состоит модель.

Рендеринг

Экран — это плоская сетка пикселей. Рендеринг — процесс, в котором движок превращает 3D-сцену в плоскую картинку и раскрашивает каждый пиксель.

Объём мы видим благодаря трём приёмам:

  • перспектива — дальние предметы меньше, параллельные линии сходятся;
  • светотень — блики, тени, полутени;
  • перекрытие — ближний предмет закрывает дальний.

Полигональная сетка (mesh)

Форму 3D-модели задаёт сетка из многоугольников-полигонов. У каждого есть вершины и рёбра. Движок разбивает всё на треугольники.

Посмотреть сетку в Unity

  1. В окне Scene открой меню Draw Mode (кнопка с шариком вверху справа).
  2. Выбери Wireframe — останутся только треугольники.
  3. Вернуть обычный вид: Shaded.

Два компонента любой 3D-модели

  • Mesh Filter — какая у объекта сетка, то есть форма.
  • Mesh Renderer — как эту сетку нарисовать, то есть материал.

У примитивов число полигонов фиксированное: растянутая сфера состоит из тех же треугольников. Сложные модели делают в отдельных 3D-программах и импортируют в Unity.

Коротко

Форма = сетка (Mesh Filter). Внешний вид = материал (Mesh Renderer). Рендеринг превращает всё это в картинку на экране.

Глава 08

Материалы

Цвет, блеск, прозрачность и свечение поверхности.

Что такое материал

Материал — ассет, который говорит движку, как выглядит поверхность: какого она цвета, гладкая ли, блестит ли. В Project он показан шариком — так удобнее рассмотреть свойства.

Как именно рисовать материал, решает шейдер. Для начала подходит универсальный Standard, он стоит по умолчанию.

Создать материал и задать цвет

  1. Создай папку Art/Materials и открой её.
  2. AssetsCreateMaterial.
  3. Назови, например, LeafGreen.
  4. В Inspector щёлкни по полоске Albedo: на круге выбери цвет, на квадрате — оттенок.
СоветЗнаешь код цвета, например #4F8F22? Вставь его в поле Hexadecimal.

Надеть материал на объект

Способ 1. Перетащи материал из Project прямо на объект в Scene.

Способ 2. Объект → Mesh Renderer → Materials → кружок справа от Element 0 → выбери материал.

Для всех экземпляров сразу — открой префаб и перетащи материал внутри Prefab Mode.

ВажноМатериал общий для всех объектов, которые его используют. Поменял цвет — поменялся везде. Нужен другой цвет для одного объекта — сделай ему отдельный материал.

Metallic и Smoothness

Smoothness — гладкость: чем выше, тем чётче блик и отражения. Metallic — металличность: металл отражает больше света, даже если шершавый. Оба параметра от 0 до 1.

Зеркало

  1. Новый материал → Metallic и Smoothness на максимум.
  2. Чтобы в нём отражались соседние объекты: объект → Add Component → RenderingReflection Probe.
  3. У Reflection Probe поставь Type = Realtime.

Reflection Probe нужен только зеркальным объектам: он нагружает компьютер.

Стекло

  1. Новый материал → Rendering Mode = Transparent.
  2. В Albedo выбери светлый цвет и уменьши A (Alpha), например до 100.

Alpha — непрозрачность: чем меньше, тем прозрачнее.

Свечение

  1. Новый материал → галочка Emission.
  2. Щёлкни по полоске Color, выбери цвет и Intensity, например 3.

Свечение лучше заметно в тёмной сцене. Подойдёт для ламп, кристаллов, волшебных предметов.

Коротко

Материал = шейдер + настройки. Albedo — цвет, Metallic и Smoothness — блеск, Transparent — прозрачность, Emission — свечение.

Глава 09

Текстуры

Картинки, которые добавляют поверхности рисунок: кирпич, дерево, камень.

Что такое текстура

Текстура — 2D-картинка (.png, .jpg и т. п.), которая передаёт детали поверхности: трещины, узоры, царапины. Её кладут в материал, а не на объект.

  • Бесшовные текстуры повторяются плиткой без заметных швов. С ними проще всего начать.
  • Текстуры для сложных моделей накладываются по специальной развёртке (UV-карте). Её делают в 3D-программах.

Импортировать текстуру

  1. Создай папку Art/Textures.
  2. AssetsImport New Asset....
  3. Выбери картинку → Import.
  4. Перенеси её в Textures.

Добавить текстуру в материал

  1. Создай материал, например StoneWall.
  2. Нажми кружок слева от Albedo и выбери текстуру.
  3. Надень материал на объект.

Цвет Albedo теперь подкрашивает текстуру, а Metallic и Smoothness работают как раньше.

Текстура растянулась? Tiling

Материал → Main Maps → Tiling. X — сколько раз повторить по ширине, Y — по высоте.

Коротко

Импорт → текстура в Albedo материала → подгонка через Tiling.

Глава 10

Готовые ассеты и быстрая сборка уровня

Где брать готовые модели и как быстро собрать комнаты и коридоры.

Unity Asset Store

Asset Store — магазин готовых моделей, текстур, звуков и инструментов. Многое там бесплатно, и небольшие команды часто собирают игры из готовых ассетов.

  1. На сайте Asset Store войди в аккаунт Unity, открой ассет и нажми Add to My Assets.
  2. В редакторе: WindowPackage Manager.
  3. Слева вверху выбери Packages: My Assets.
  4. Выбери пакет → Download → Import.
  5. В списке файлов отметь нужное (если не уверен — всё) и снова Import.
  6. Перенеси папку пакета в ThirdParty.
ВажноНе меняй папки внутри скачанного пакета — ассеты могут сломаться. Готовые модели обычно лежат в его папке Prefabs.

Почему сквозь модели можно пройти

Твёрдость объекту даёт коллайдер — невидимая оболочка для физики. У примитивов он есть сразу, а у многих скачанных моделей его нет. Для черновика уровня это не страшно.

Лайфхак: префаб пола

  1. Cube → имя Floor.
  2. Position (0; 0; 0), Scale (10; 0.5; 10).
  3. Сделай из него префаб.

Получится квадратная плита 10 × 10 м толщиной полметра.

Лайфхак: коридор

  1. Cube Wall вложи в Floor.
  2. Scale (1; 5; 0.1), Position (0; 3; -0.45).
  3. Ctrl+D, у копии Position (0; 3; 0.45).
  4. Floor со стенами → в Project → Original Prefab → Corridor.

Числа маленькие, потому что стены считаются от размера пола-родителя: 0.45 — почти у самого края.

Лайфхак: комната с двумя проходами

  1. Внутри Floor продублируй Wall → Doorway.
  2. Rotation Y 90, Scale (0.3; 5; 0.1).
  3. Сделай четыре таких куска:
КусокPosition
1(-0.45; 3; -0.3)
2(-0.45; 3; 0.3)
3(0.45; 3; 0.3)
4(0.45; 3; -0.3)

Floor → в Project → Original Prefab → Room. Меняй Scale родителя — комната растянется целиком.

Коротко

Готовое берём в Asset Store через Package Manager и складываем в ThirdParty. Типовые части уровня делаем префабами.

Глава 11

Персонаж и тестирование

Как пройтись по своему уровню от первого лица и проверить, что всё работает.

Режим игры

Кнопка ▶ Play вверху редактора запускает игру прямо в окне Game. Повторное нажатие останавливает её.

ВажноВсё, что меняешь во время Play, после остановки откатится. Сначала останови игру, потом правь сцену.

Добавить персонажа

  1. Импортируй пакет с готовым персонажем, например Mini First Person Controller из Asset Store.
  2. Перетащи префаб First Person Controller в точку старта.
  3. У Main Camera сними галочку с Audio Listener: у персонажа своя камера.
  4. Play → ПКМ по экрану игры, чтобы управлять камерой. Esc — отпустить курсор.

Ходьба — WASD. Клавиши бега, прыжка и приседания видно в компонентах персонажа в Inspector.

Что такое тестирование

Тестирование — сравнение того, что ожидали, с тем, что получилось.

ОжидалиПолучилось
игрок допрыгивает до любой платформыдо двух платформ не допрыгнуть — стоят слишком далеко

Найденное расхождение — повод исправить уровень.

Как давать отзыв на чужую игру

  1. Начни с того, что понравилось.
  2. Назови, что стоит доработать, и предложи как.
  3. Оценивай игру, а не автора.
Глава 12

Сборка игры (WebGL)

Как превратить проект в игру, которая запускается в браузере.

Что такое билд

Билд — собранная из проекта готовая программа для конкретной платформы: Windows, Android, браузера. WebGL-билд запускается в браузере, его удобно выкладывать на сайты.

Собрать WebGL-билд

  1. FileBuild Settings.
  2. Add Open Scenes — добавить открытую сцену в сборку.
  3. Выбери WebGL. Нет модуля — Install with Unity Hub.
  4. Switch Platform и подожди.
  5. Player Settings... → Publishing Settings: Compression Format = Disabled, галочка Decompression Fallback.
  6. Закрой окно → Build → создай новую папку с именем игры и выбери её. Не внутри Assets.

В выбранной папке появятся файл index.html и папки с данными игры. Это и есть сайт с игрой.

Коротко

Build Settings → сцена → WebGL → Switch Platform → настройки сжатия → Build в отдельную папку.

Глава 13

Ландшафт: рельеф

Объект Terrain: горы, впадины, уступы и склоны.

Что такое Terrain

Terrain — большая плоскость с очень гибкой сеткой. Её «лепят» кистями, как песок.

  1. GameObject3D ObjectTerrain.
  2. Отдали камеру — плоскость огромная.

Компоненты: Transform, Terrain (форма, цвет и все инструменты) и Terrain Collider (чтобы по земле можно было ходить).

Инструменты Terrain

Шаг 1. Удобный размер

  1. Terrain Settings (шестерёнка) → раздел Mesh Resolution.
  2. Terrain Width и Terrain Length = 50, Terrain Height = 60.

Это ширина, длина и максимальная высота. Для правдоподобия важны не реальные размеры, а соотношение: гора намного выше персонажа.

Шаг 2. Толщина земли

  1. Paint Terrain → Set Height.
  2. Height = 8 → Flatten All.

Земля поднимется на 8 м. Без этого нельзя «копать» вниз: озёра и ущелья не получатся.

Шаг 3. Горы, впадины, уступы

  • Поднять: Raise or Lower Terrain, зажми ЛКМ. Опустить: то же с Shift.
  • Brush Size — размер кисти, Opacity — сила. Сильной кистью делай основной объём, слабой — сглаживай и добавляй детали.
  • Кисти с мягким краем дают плавные холмы, ровные — плато, острые — скалы.
  • Уступ: Set Height, наведи на гору и щёлкни с Shift — высота точки появится в поле Height. Уменьши её на высоту прыжка и закрась площадку.
  • Склон: поставь высоту чуть ниже уступа (на 0.5), возьми мягкую маленькую кисть и аккуратно проведи между уступами.

Коротко

Размер → толщина (Set Height + Flatten All) → основной объём → детали. Проверяй уровень персонажем: нигде не застревает, через край не уйти.

Глава 14

Ландшафт: текстуры и природа

Раскрашиваем землю, рисуем дорожки, добавляем воду, деревья и траву.

Слои земли: Terrain Layer

  1. Импортируй бесшовную текстуру земли в Art/Textures.
  2. Paint Terrain → Paint Texture → Edit Terrain Layers... → Create Layer.
  3. Дважды щёлкни по текстуре.
  4. В Assets появится ассет New Layer — переименуй, например в Ground.
ВажноПервый слой сразу покрывает весь ландшафт, поэтому для него нужна бесшовная текстура.

Неровности: Normal Map

Карта нормалей — особая текстура, которая хранит неровности поверхности. С ней земля выглядит рельефной, хотя сетка не меняется.

  1. Импортируй карту нормалей к своей текстуре.
  2. В её настройках Texture Type = Normal Map → Apply.
  3. Открой свой Terrain Layer → поле Normal Map → Select → выбери карту.

Силу рельефа меняет Normal Scale, повтор — Tiling Settings.

Дорожки вторым слоем

  1. Создай второй слой с другой текстурой (грунт, песок) и назови Path.
  2. Выбери его в списке Terrain Layers.
  3. Подбери кисть и нарисуй дорожки.

Ошибся — выбери первый слой и закрась лишнее.

Вода

  1. Импортируй бесплатный пакет воды, например AQUAS Lite, в ThirdParty.
  2. Появилась папка _TerrainAutoUpgrade? Её можно удалить.
  3. Из папки Prefabs пакета перетащи воду на сцену и подгони под впадину.

Цвет: Main Color — у поверхности, Deep Water Color — на глубине.

Деревья

  1. Импортируй модель дерева.
  2. Paint Trees → Edit Trees... → Add Tree.
  3. Кружок → выбери модель → Add.
  4. Настрой Brush Size, Tree Density (густота) и Tree Height, потом «сажай» кистью.

Трава и цветы

  1. Импортируй текстуру травы.
  2. Paint Details → Edit Details... → Add Grass Texture.
  3. Кружок → выбери текстуру → Add.
  4. Настрой кисть и рисуй.

Коротко

Земля — Terrain Layers (первый слой бесшовный, Normal Map для рельефа). Вода — готовый префаб. Деревья — Paint Trees, трава — Paint Details.

Глава 15

Свет

Виды источников света, время суток и приёмы светового дизайна.

Три основных источника

Главные настройки Light

  • Type — вид источника.
  • Color — цвет света.
  • Intensity — яркость.
  • Range — дальность (у Point и Spot).
  • Mode — Realtime (считается в игре) или Baked (заранее).
  • Shadow Type — какие тени.

Свет — это компонент. Объект с ним освещает всё вокруг, но сам не светится: для этого нужен материал с Emission.

Время суток

Выбери Directional Light и меняй Rotation X: 0 — рассвет, 90 — полдень, 180 — закат, от 180 до 360 — ночь. Rotation Y — с какой стороны светит солнце.

Фонарь

  1. Поставь на сцену модель фонаря (пакет импортируется через AssetsImport PackageCustom Package...).
  2. Создай Point Light и в Hierarchy перетащи его внутрь фонаря.
  3. Сдвинь свет туда, где лампа. Настрой Color, Intensity и Range.
  4. Если фонарь — префаб: Overrides → Apply All.
Иконки мешают?В окне Scene открой Gizmos и уменьши 3D Icons.

Прожектор

  1. GameObjectLightSpotlight.
  2. Поверни его E так, чтобы конус падал на нужное место.
  3. Настрой Range, Intensity и цвет.
СоветТрудно попасть светом в точку? Поставь туда куб и ориентируйся по его координатам.

Запечь свет

Запечённый (Baked) свет рассчитывается один раз заранее, а не каждый кадр, поэтому игра работает быстрее.

  1. У каждого источника поставь Mode = Baked.
  2. Если свет пропал: WindowRenderingLighting → Generate Lighting.

Для чего свет на уровне

  • Атмосфера. Тёплый и яркий — уют и радость. Холодный и тусклый — тревога.
  • Навигация. Яркое пятно в темноте ведёт игрока, как маяк.
  • Геймплей. В стелс-играх игрок прячется в тени, поэтому нужен сильный контраст.

Приёмы светового дизайна

  1. Начинай с Directional Light — это ключевой свет, он задаёт тон всей сцене. Потом расставляй заполняющие источники: точечные и прожекторы.
  2. Свет у важных мест делай ярче и контрастнее, свет для атмосферы — мягче.
  3. Собери референсы: кадры из фильмов, фото, других игр.
Глава 16

Основы дизайна уровня

Как придумать и спланировать уровень, прежде чем строить его в Unity.

Из чего состоит игра

  • Механики — что игрок может делать: ходить, прыгать, подбирать.
  • Динамика — как механики работают вместе и делают игру интересной.
  • Эстетика — сюжет, графика и звук, то есть какие чувства вызывает игра.

Механики определяют уровень: если игрок умеет прыгать, нужны платформы.

Сначала прототип

Идея→Прототип→Тест→Исправления↺

Прототип — упрощённая версия, чтобы быстро проверить идею. Первая идея редко бывает лучшей, поэтому этот круг повторяют несколько раз.

Дизайн-документ

Документ, где записано всё о будущей игре. Идея отвечает на четыре вопроса:

  1. Какая цель у героя?
  2. Что ему мешает?
  3. Как он добивается цели?
  4. Где и когда всё происходит (сеттинг)?

Типы уровней

  • Линейный — один путь. Сложность растёт от локации к локации, между трудными участками нужны передышки.
  • Разветвлённый — есть выбор пути. Ветки должны отличаться, иначе игрок запутается.
  • Тайные места с наградами прячут за потайными ходами в стороне от основного пути.
  • Хаб — большая безопасная локация, которая связывает другие: база, магазин, площадка перед боссом.

Схема уровня

Схему рисуют условными знаками, без деталей:

  • места: пути, локации, хаб, тайные локации, потайные ходы;
  • объекты: старт игрока, враги, ключевые предметы, награды, финиш.
СоветДля первого уровня хватит 3–5 локаций.

Пузырьковая диаграмма

Круги — локации: чем больше круг, тем больше и выше место. Стрелки — направление и тип пути. Удобно для открытого мира, обычно 5–7 локаций.

Как не дать игроку потеряться

  • Границы — то, что не пускает за край: море, высокие горы.
  • Ориентиры — то, что выделяется на фоне и видно издалека: вулкан, башня.
  • Путь к цели не прямой: пусть игрок ищет переправу через реку.
  • С возвышенности игрок видит местность и сам выбирает дорогу.

Визуальный стиль

  1. Соответствует истории мира (лору).
  2. Передаёт место и время — сеттинг. Для природы это ещё и биом: жаркий, умеренный или холодный.
  3. Создаёт настроение: тёплые или холодные, светлые или тёмные цвета.
  4. Помогает ориентироваться: контрастный цвет подсказывает, куда идти и с чем можно взаимодействовать.

Доска настроения

Moodboard — коллаж из картинок и цветов, который задаёт стиль уровня. Его удобно собирать в онлайн-сервисах вроде Milanote:

  • картинки берут на бесплатных фотостоках (Unsplash, Freepik);
  • раскладывают по колонкам: рельеф, растения, небо;
  • пипеткой собирают палитру из 5–6 цветов — их коды потом вставляют в Unity в поле Hexadecimal.
Глава 17

Визуальные эффекты: система частиц

Дым, огонь, искры и снег из тысяч маленьких картинок. На примере костра.

Зачем нужны эффекты

Модели, материалы и свет делают мир красивым, но неживым. В жизни вещи взаимодействуют со средой: костёр трещит, дымит и разбрасывает искры. Без этого даже хороший уровень похож на макет.

  • VFX-художник (художник по визуальным эффектам) делает взрывы, дым, магию, брызги.
  • Саунд-дизайнер отвечает за звуки мира: шаги, ветер, шум города.

Два способа создать систему частиц

  1. Готовый объект через меню выше. Частицам сразу назначен Default Particle Material.
  2. Компонент на любой объект: Add Component → Effects → Particle System. Материала у частиц не будет.
Розовые частицы?Розовым Unity красит всё, у чего нет материала. Назначь материал в модуле Renderer.

Как устроена система частиц

  • Particle System — компонент, который отвечает за эффекты из частиц.
  • Эмиттер (от англ. emit — «излучать») — точка, из которой вылетают частицы. Это начало координат объекта с компонентом.
  • Билборд — плоская картинка, всегда повёрнутая к камере. Тысячи таких картинок выглядят как объёмный дым, а компьютер почти не нагружается.

Предпросмотр в окне Scene

Кнопками можно остановить эффект, запустить заново, замедлить. На игру это не влияет: это только просмотр в редакторе.

Модули

Компонент разбит на модули, каждый отвечает за свою группу настроек. Дополнительные модули включают и выключают галочкой. Сразу включены Emission, Shape и Renderer.

Основной модуль

СвойствоЗа что отвечает
Durationсколько секунд длится один цикл эффекта
Loopingповторять эффект по кругу. Без галочки частицы перестанут вылетать через Duration секунд
Start Lifetimeсколько секунд «живёт» каждая частица, потом исчезает
Start Speedскорость, с которой частица вылетает
Start Sizeразмер частицы в метрах
Start Rotationповорот картинки частицы в градусах
Max Particlesсколько частиц может быть одновременно (по умолчанию 1000)
ЛайфхакНажми стрелку ▾ справа от свойства и выбери Random Between Two Constants. Тогда у каждой частицы будет случайное значение из диапазона. В жизни все частицы разные, поэтому эффект выглядит живее. Constant — одно значение для всех.

Emission: сколько частиц

Rate over Time — сколько частиц вылетает за секунду. Меньше — эффект реже и прозрачнее, больше — гуще.

Для лёгкого дымка над костром хватит 5.

Shape: форма эмиттера

  • Shape — форма: конус (Cone), сфера, коробка (Box) и другие.
  • Radius — радиус основания конуса.
  • Angle — насколько конус расширяется. 0 — частицы летят ровным столбом.
  • Position, Rotation, Scale — где стоит эмиттер, куда повёрнут и какого он размера.

Форму можно менять и прямо в окне Scene, перетаскивая точки на контуре.

Renderer: материал частиц

  1. Создай материал, Shader = ParticlesStandard Unlit.
  2. Выбери Rendering Mode.
  3. В Albedo положи текстуру частицы (мягкое пятно на прозрачном фоне) и выбери оттенок.
  4. Перетащи материал в поле Material модуля Renderer.
  • Fade — обычная полупрозрачность: дым, пыль, туман.
  • Additive — цвет частиц прибавляется к фону, и они светятся: огонь, искры, магия.

Color over Lifetime: цвет за время жизни

  1. Включи модуль Color over Lifetime и кликни по полосе Color.
  2. Левые маркеры — начало жизни частицы, правые — конец.
  3. Клик по нижнему маркеру меняет цвет, по верхнему — прозрачность.
  4. Клик по пустому месту у верхнего или нижнего края полосы добавляет маркер. Чтобы удалить маркер, утащи его за пределы окна.
СоветСделай частицы прозрачными в начале и в конце жизни. Тогда они плавно появляются и тают, а не возникают и пропадают резко.

Рецепт: костёр из трёх эффектов

Каждый эффект — отдельный объект Particle System, вложенный в модель костра с Position (0, 0, 0). Сначала делают дым, потом по его образцу пламя и искры.

Лайфхак: снег или дождь

  1. Создай Particle System и подними его высоко над уровнем.
  2. Rotation X = 90, чтобы частицы летели вниз.
  3. В Shape выбери Box и растяни Scale по X и Y на весь уровень.
  4. Маленький Start Size, большой Rate over Time. Start Lifetime сделай таким, чтобы частицы успевали долететь до земли.
  5. Если снег редкий, увеличь Max Particles.

Коротко

Particle System выпускает из эмиттера частицы-картинки. Основной модуль задаёт жизнь, скорость и размер, Emission — количество, Shape — форму, Renderer — материал, Color over Lifetime — цвет и прозрачность.

Глава 18

Звук в игре

Кто слышит, кто звучит и как сделать, чтобы звук затихал вдали.

Слушатель и источник

  • Audio Listener («слушатель») — «уши» игры. Он один на сцене. Обычно он стоит на Main Camera, а когда есть персонаж — на камере персонажа.
  • Audio Source («источник звука») — то, что звучит. Источников сколько угодно, им может быть любой объект, даже сам слушатель.
Два слушателяЕсли в Console жалобы на два Audio Listener, выключи лишний у Main Camera.

Добавить звук объекту

  1. Перетащи звуковой файл (.wav, .mp3 или .ogg) в окно Project.
  2. Выбери объект, например костёр: Add Component → Audio → Audio Source.
  3. В поле AudioClip нажми кружок ⊙ справа и выбери звук. Или перетащи файл в поле.
  4. Поставь галочку Loop, если звук должен повторяться: треск огня, шум реки.
  5. Запусти игру и подойди к объекту.

Audio Source в Inspector

  • Play On Awake — играть сразу после запуска игры.
  • Volume — громкость от 0 до 1.
  • Mute — выключить звук этого источника.

2D или 3D звук

По умолчанию звук двумерный: его одинаково слышно в любой точке уровня, даже на другом конце карты. Чтобы звук затихал вдали, сделай его пространственным:

  1. Передвинь ползунок Spatial Blend до упора вправо, на 3D.
  2. Раскрой 3D Sound Settings и задай Max Distance, например 6 метров для костра.
  • Min Distance — ближе этого расстояния звук играет на полной громкости.
  • Max Distance — до этого расстояния звук затихает. Дальше он тише уже не становится.
  • Volume Rolloff — как именно затихает. Выбери Linear Rolloff, если звук должен совсем пропадать на Max Distance.
Что куда2D — фоновая музыка и звуки интерфейса. 3D — всё, что звучит в определённом месте: костёр, водопад, враг.

Звуки для атмосферы

  • Звук делает место живым: у костра — треск и сверчки, у реки — плеск, на горе — ветер.
  • Тихие фоновые звуки ставь с Loop, чтобы они не обрывались.
  • Звук подсказывает дорогу: игрок пойдёт на шум водопада, даже если его не видно.
  • Бесплатные звуки есть в Asset Store: ищи по словам free sound или SFX.

Коротко

Слушатель один, источников много. Звук объекту: Add Component → Audio → Audio Source → AudioClip → Loop. Чтобы затихал вдали: Spatial Blend на 3D и Max Distance.

Глава 19

Как представить свой проект

Как за пару минут рассказать о своём уровне так, чтобы было интересно.

Зачем показывать проект

Когда делишься работой, получаешь отзывы и сам учишь других. Разработчики игр постоянно выступают с докладами о том, как сделали свои игры. Самая крупная такая конференция — GDC (Game Developers Conference). Она проходит каждый год в Сан-Франциско.

Какие бывают презентации

  • Подробная — много текста на слайдах. Её можно читать без докладчика.
  • Быстрая — на слайде только заголовок и картинка, остальное ты рассказываешь вслух.

Чтобы за 3 минуты показать проект от идеи до результата, подходит быстрая. Заголовок слайда сразу говорит, о чём он.

Рассказывай, а не описывай

Не пересказывай, что на картинке: «тут гора, тут река». Расскажи то, что знаешь только ты: какая идея была в начале, почему схема уровня именно такая, откуда взялись цвета доски настроения, что было трудно.

О чём можно рассказать

  1. Идея и сеттинг: где и когда всё происходит.
  2. Схема уровня или пузырьковая диаграмма.
  3. Доска настроения и палитра.
  4. Ландшафт, свет и эффекты: скриншоты из Unity.
  5. Что хочешь улучшить дальше.
СоветНет схемы или доски настроения? Покажи картинки, которые тебя вдохновили.

Когда выступают другие

  • Слушай внимательно и задавай вопросы о том, что зацепило.
  • Волноваться перед выступлением нормально. Все учатся, а без проб и ошибок научиться нельзя.
  • Поддерживай: начни отзыв с того, что получилось.

Коротко

Быстрая презентация: заголовок + картинка на слайде, рассказ голосом. Говори об идее и решениях, а не о том, что и так видно.

Приложение Б

Если что-то не работает

Потерял объект на сцене

Выбери его в Hierarchy и нажми F.

Изменения пропали после остановки игры

Правки во время Play не сохраняются. Останови игру и правь заново.

Копия объекта «не появилась»

Она стоит ровно на месте оригинала. Сдвинь её клавишей W.

Пол пропадает, если смотреть снизу

Plane видна только сверху — это нормально.

После работы в проводнике пропали объекты

Файлы из Assets трогай только в окне Project.

Экземпляр префаба ставится со смещением

Группируй через Create Empty Parent, а не через Create Empty.

Синяя полоска слева от объекта

Изменения не попали в префаб: Overrides → Apply All.

Настройки материала серые

Это Default Material, его менять нельзя. Создай свой.

Перекрасил один объект, а перекрасились все

У них общий материал. Сделай отдельный.

Текстура растянута или слишком мелкая

Настрой Tiling в материале или Tiling Settings в Terrain Layer.

Поверхности мерцают при движении камеры

Две поверхности совпадают и «спорят», какую рисовать. Чуть сдвинь один объект.

Прохожу сквозь скачанные модели

У них нет коллайдера. Для черновика уровня это нормально.

Жёлтые треугольники в Console

Это предупреждения, игре они не мешают.

Сообщение про два Audio Listener

Выключи Audio Listener у Main Camera.

Нет пакета в Package Manager

Проверь вход в аккаунт Unity и Add to My Assets, потом обнови список.

Ошибка «…incompatibility between Color Space…» при сборке

Player Settings → Other Settings: Color Space = Gamma, Lightmap Encoding = Normal Quality.

WebGL-игра не запускается

Включи Decompression Fallback, удали старый билд и собери заново.

Не получается сделать впадину

Сначала дай земле толщину: Set Height → Flatten All.

Кисть красит не той текстурой

Выбери нужный слой в Terrain Layers.

Сцена стала совсем тёмной

Проверь Rotation X у Directional Light: от 180 до 360 — ночь.

Частицы розовые

У них нет материала. Назначь его в поле Material модуля Renderer.

Частицы — квадраты с фоном

В материале частиц поставь Rendering Mode = Fade или Additive и проверь, что у текстуры прозрачный фон.

Эффект проиграл один раз и пропал

Включи Looping в основном модуле.

Частицы появляются и исчезают резко

В Color over Lifetime сделай прозрачными начало и конец.

Звук одинаково громкий везде

Spatial Blend = 3D и задай Max Distance.

Звук затихает, но не пропадает

Volume Rolloff = Linear Rolloff.

Звука нет совсем

Проверь AudioClip, Mute, Volume и Play On Awake. В окне Game не должна быть нажата кнопка Mute Audio.
