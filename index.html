Как хранить папки проекта

UnityProjects/        ← на диске, где 50+ ГБ
└─ МойПроект/
   └─ Assets/
      ├─ Levels/
      │  ├─ Scenes/       ← сцены
      │  └─ Prefabs/      ← префабы
      ├─ Art/
      │  ├─ Materials/    ← материалы
      │  └─ Textures/     ← текстуры
      └─ ThirdParty/      ← всё скачанное

Три правила, которые спасают проект

  1. Папки и файлы из Assets двигай, переименовывай и удаляй только внутри Unity, в окне Project. Если сделать это в проводнике, могут пропасть объекты или целый уровень.
  2. Объекты называй по-английски: Tree, Tower, Cube_1. Если не знаешь слово, загляни в переводчик.
  3. Ассеты и папки называй в стиле PascalCase, то есть слова слитно и каждое с большой буквы: CrownColor, WallStone, ThirdParty.
Не забудьСохраняй сцену почаще: Ctrl+S.
Модуль 1 · Урок 1

Знакомство с Unity

Создаём проект, учимся ставить примитивы на сцену и управлять ими.

Создать новый проект

  1. Один раз создай на диске папку UnityProjects (где свободно не меньше 50 ГБ).
  2. Открой Unity Hub → вкладка Projects.
  3. Нажми New Project.
  4. Выбери шаблон 3D (Core).
  5. Впиши имя проекта и укажи путь до папки UnityProjects.
  6. Нажми Create project.

Создать папку в окне Project

  1. Щёлкни по папке Assets.
  2. ПКМ по пустому месту окна Project → CreateFolder.
  3. Впиши имя, например Levels.
  4. Перетащи в неё папку Scenes.

Объект и компоненты

Объект в Unity сам по себе пустой, как котелок. Компоненты — это ингредиенты: что положишь, то и получишь (свет, персонажа, препятствие).

  • Компоненты объекта видны в окне Inspector.
  • Transform (положение, поворот, размер) есть у каждого объекта, удалить его нельзя.
  • Убрать компонент: три точки ⋮ справа от его названия → Remove Component.
  • Вернуть удалённое: Ctrl+Z.

Создать 3D-объект (примитив)

  1. Верхняя панель → GameObject3D Object.
  2. Выбери нужный: Cube, Sphere, Cylinder, Capsule, Plane.
ПримитивИз него можно сделать
Cubeстены, коробки, ступеньки
Sphereмячи, планеты, снаряды, крону дерева
Cylinderстволы деревьев, колёса
Capsuleперсонажа
Planeпол и стены уровня
ВажноPlane односторонний. Снизу его не видно, видна только верхняя сторона.

Переименовать объект

  1. Выбери объект в Hierarchy.
  2. ПКМ → Rename.
  3. Сотри старое имя и впиши новое, например Cube_1.
ПравилоИмена объектов только на английском.

Двигать, вращать, менять размер

  • W двигать, E вращать, R менять размер.
  • Каждая ось своего цвета: X — красная, Y — зелёная, Z — синяя. Тяни за ось того цвета, по которой хочешь изменить объект.
  • Увеличить объект целиком: R → зажми ЛКМ на кубике в центре осей → тяни вверх (больше) или вниз (меньше).
  • Точные числа можно вписать в Transform в Inspector: Position, Rotation, Scale.

Дублировать и выделить несколько

  1. Выбери объект в Hierarchy → ПКМ → Duplicate (или Ctrl+D).
  2. Копия появляется ровно на месте оригинала, поэтому её не видно. Сдвинь её с помощью W.

Выделить несколько: зажми Shift и щёлкай по объектам. Их можно двигать, вращать и масштабировать все вместе. Снять выделение: клик по пустому месту.

Режим полёта и «я потерялся»

  • Зажми ПКМ в окне Scene и лети: WASD, вниз Q, вверх E.
  • Потерял объект из виду: выбери его в Hierarchy и нажми F (или дважды щёлкни по нему). Камера сама подлетит к нему.

Удалить объект и сохранить сцену

  • Удалить: выбери объект(ы) в Hierarchy (несколько с Ctrl) → ПКМ → Delete.
  • Сохранить: FileSave или Ctrl+S.

Поменять освещение сцены

  1. Выбери в Hierarchy Directional Light. Это «солнце» сцены.
  2. Нажми E (вращение) и поверни его. Сцена станет светлее или темнее.

В новой сцене сразу есть два объекта: Main Camera (камера) и Directional Light (свет).

Модуль 1 · Урок 2

Игровые объекты и префабы

Собираем сложные объекты из частей и делаем шаблоны, чтобы быстро наполнять уровень.

Сгруппировать объекты (правильный способ)

  1. Выдели все части, например ствол и крону дерева.
  2. ПКМ по ним → Create Empty Parent.
  3. Назови контейнер по-английски: Tree.
Почему не Create EmptyПустой объект появится не в центре частей. Потом префаб будет ставиться на сцену криво.

Родитель и дочерние объекты

  • Контейнер — родитель, вложенные в него объекты — дочерние (по-английски child).
  • Дети двигаются вместе с родителем.
  • Их Transform считается от центра родителя, а не от центра сцены. Когда двигаешь весь объект, числа меняются только у родителя.

Создать префаб

  1. Создай папку Levels/Prefabs.
  2. Перетащи объект из Hierarchy в окно Project (в папку Prefabs).
  3. Объект в Hierarchy стал голубым. Голубым отмечаются все экземпляры префаба.

Префаб — это файл. Он останется на компьютере, даже если ты забыл сохранить сцену.

Поставить экземпляр префаба

Перетащи префаб из окна Project в окно Scene. Экземпляр, в отличие от простого дубликата, связан с префабом: поменяешь префаб, и поменяются все экземпляры.

Изменить префаб: Prefab Mode

Префаб открывается отдельно от сцены.

  1. Выбери префаб в окне Project.
  2. Нажми Open вверху справа в Inspector (или дважды щёлкни по префабу).
  3. Внеси изменения.
  4. Выход: стрелочка в левом верхнем углу окна Hierarchy.

Изменить префаб: Prefab in Context

Префаб открывается прямо среди других объектов сцены. Удобно, когда надо подогнать, например, стулья под высоту стола.

  1. Выбери любой экземпляр в Hierarchy.
  2. Нажми Open вверху справа в Inspector.
  3. Выход: стрелочка в левом верхнем углу Hierarchy.

В обоих режимах изменения сразу попадают во все экземпляры.

Голубая полоска у экземпляра

Ты поменял экземпляр без специального режима, и изменения ещё не попали в префаб. Новые части отмечены плюсом.

  1. Выбери изменённый экземпляр.
  2. В Inspector вверху справа нажми Overrides.
  3. Нажми Apply All.

Новый префаб на основе старого

  1. Перетащи экземпляр префаба в окно Project.
  2. В появившемся окне выбери Original Prefab.

Старый и новый префабы никак не связаны: можно менять новый, не трогая старый.

Удалить префаб

  1. Выбери префаб в Project → ПКМ → Delete.
  2. Нажми Delete and unpack.

Удалится сам префаб, а экземпляры на сцене останутся обычными объектами.

ВажноЭто действие нельзя отменить.

Осмотреть объект со всех сторон

В правом верхнем углу окна Scene есть гизмо сцены — значок с осями. Щёлкни по конусу оси, чтобы посмотреть с этой стороны: зелёный (Y) — вид сверху, красный (X) и синий (Z) — виды сбоку. Название вида написано под гизмо.

Модуль 1 · Урок 3

Материалы и текстуры

Форму объекта задаёт полигональная сетка, а цвет и поверхность — материал. Учимся создавать материалы и накладывать текстуры.

Два главных компонента 3D-объекта

  • Mesh Filter отвечает за форму: какая полигональная сетка у объекта.
  • Mesh Renderer отвечает за отрисовку: какой у объекта материал.

Посмотреть сетку из полигонов

  1. В правом углу окна Scene открой меню Draw Mode (иконка с шаром).
  2. Выбери Wireframe. Видны треугольники сетки.
  3. Чтобы вернуть обычный вид, выбери Shaded.

Сколько полигонов: Mesh Filter → кружок справа от Mesh → информация внизу окна. Например, у сферы 768 треугольников, и это число не меняется, если её растянуть.

Создать материал

  1. Создай папки Art/Materials.
  2. Открой папку Materials → верхняя панель AssetsCreateMaterial.
  3. Назови в стиле PascalCase: CrownColor, WallColor.

На курсе используем шейдер Standard, он стоит по умолчанию.

Задать цвет: Albedo

  1. Выбери материал в окне Project.
  2. В Inspector найди Albedo и щёлкни по белой полоске.
  3. На большом круге выбери цвет, на квадрате — оттенок.
ЛайфхакЗнаешь код цвета? Вставь его в поле Hexadecimal.

Надеть материал на объект

Способ 1. Перетащи материал из окна Project прямо на объект в окне Scene.

Способ 2.

  1. Выбери объект → в Inspector компонент Mesh Renderer → Materials.
  2. Нажми кружок с точкой справа от Element 0.
  3. Выбери материал из списка.

Для всех деревьев сразу: открой префаб в Prefab Mode и перетащи материал на крону.

Не тот материал? Тем же кружком выбери другой. Исходный называется Default Material.

Metallic и Smoothness

Metallic — металличность, Smoothness — гладкость. Значения от 0 до 1. Гладкое чётко отражает свет (виден блик), металл блестит сильнее, даже если шершавый.

ПредметMetallicSmoothness
Лист бумаги00.01
Апельсин00.3
Металлическая ручка0.90.5

Зеркальный материал

  1. Создай материал CrownMirror.
  2. Ползунки Metallic и Smoothness до конца вправо.
  3. Надень на объект.
  4. Чтобы он отражал окружение: выбери объект → Add Component → RenderingReflection Probe.
  5. В Reflection Probe поставь Type = Realtime.
ВажноReflection Probe добавляй только к объекту с зеркальным материалом.

Стеклянный (прозрачный) материал

  1. Создай материал CrownGlass.
  2. Rendering Mode → Transparent.
  3. В Albedo выбери белый цвет и впиши A (Alpha) = 100.

Alpha — непрозрачность: чем меньше число, тем прозрачнее.

Светящийся материал

  1. Создай материал CrownGlow.
  2. Поставь галочку Emission.
  3. Нажми на чёрную полоску справа от Color, выбери цвет и Intensity = 3.

Свечение лучше видно, если сделать на сцене вечер (поверни Directional Light).

Импортировать текстуру

  1. Создай папку Art/Textures.
  2. Скачай картинку с текстурой на компьютер.
  3. В Unity: AssetsImport New Asset....
  4. Найди файл → Import.
  5. Перенеси текстуру в папку Textures.

Подходят файлы .png, .jpg, .gif, .bmp.

Добавить текстуру в материал

  1. Создай материал, например WallStone.
  2. Нажми кружок рядом с Albedo и выбери текстуру.
  3. Надень материал на объект.
ВажноТекстура кладётся в материал, а не на сам объект.

Текстура растянулась: Tiling

  1. Выбери материал → раздел Main Maps → Tiling.
  2. X — сколько раз текстура повторится в ширину, Y — в длину. По умолчанию 1; 1.
  3. Увеличивай числа, пока не станет красиво.

Оттенок текстуры меняется цветом Albedo. Metallic и Smoothness тоже работают.

Один материал на многих объектах

Материал — это ассет, как и префаб. Если поменять материал у одного объекта, он поменяется у всех объектов с этим материалом. Нужен другой цвет только для одного объекта? Создай для него отдельный материал.

Модуль 1 · Урок 4 · Творческий

Планирование уровня

Перед тем как строить уровень, придумываем идею, записываем её в дизайн-документ и рисуем схему.

Как делают игру на старте

Подготовка игры (пре-продакшн) идёт по кругу:

  1. Придумать идею.
  2. Сделать прототип — простую модель, чтобы быстро проверить идею.
  3. Протестировать прототип.
  4. Исправить и снова протестировать.

Первая идея не всегда лучшая, и это нормально.

Дизайн-документ

В дизайн-документе записывают всё о будущей игре: идею, сеттинг, схему уровня. Он помогает упорядочить идею, следить за прогрессом и работать в команде.

Идея игры отвечает на 4 вопроса:

  1. Какая цель у героя?
  2. Какие препятствия встречаются на пути?
  3. Как герой добивается цели?
  4. Где и когда всё происходит (сеттинг)?
ЛайфхакНе пытайся сразу написать идеально. Документ всегда можно доработать.

Типы уровней

  • Линейный — один путь от начала до конца. Сложность растёт от локации к локации, и нужны места, где можно передохнуть.
  • Разветвлённый — есть выбор пути. Локации на разных ветках должны отличаться, иначе игрок запутается.
  • Тайные места и потайные ходы — секреты с ценными предметами в стороне от основного маршрута.
  • Хаб — большая безопасная локация: штаб, магазин, точка перед боссом.

Схема уровня

На схеме не рисуют детали, только условные обозначения:

  • Места: путь, обычные локации, хаб, тайные локации, потайной ход.
  • Объекты: место появления игрока, враги, ключевые предметы для прохождения, ценные предметы, цель (финиш).

От механик зависит устройство уровня: если игрок умеет прыгать, на уровне нужны платформы.

ЛайфхакДержи схему маленькой: 3–5 локаций. Её проще быстро собрать и проверить.

Как давать обратную связь

  1. Скажи, что понравилось больше всего.
  2. Назови, что доработать, и предложи, как это сделать.
  3. Оценивай проект, а не человека.
Модуль 1 · Урок 5 · Творческий

Сборка уровня, персонаж и билд

Строим прототип по своей схеме, добавляем персонажа и собираем игру в билд.

Скачать ассеты из Unity Asset Store

  1. Открой страницу нужного ассета в Unity Asset Store. Проверь, что ты вошёл в аккаунт Unity.
  2. Нажми Add To My Assets и согласись с лицензией.
  3. В Unity создай папку ThirdParty.
  4. WindowPackage Manager.
  5. Слева вверху нажми Packages: ... → My Assets.
  6. Найди пакет → Download → дождись → Import.
  7. В окне со списком файлов нажми Import. Если не знаешь, что нужно, импортируй всё.
  8. Перенеси папку пакета в ThirdParty.

Нет нужного пакета в списке? Нажми стрелку обновления.

ВажноНе меняй папки внутри скачанного пакета, иначе ассеты могут сломаться. Готовые модели обычно лежат в его папке Prefabs: перетащи нужную в окно Scene.

Лайфхак: префаб пола

  1. Создай Cube и назови Floor.
  2. Position: (0; 0; 0).
  3. Scale: (10; 0.5; 10). Получится квадратный пол толщиной 0.5 м.
  4. Сделай из него префаб.

Лайфхак: префаб коридора

  1. Создай Cube Wall и вложи его в Floor (перетащи в Hierarchy).
  2. Scale стены: (1; 5; 0.1), Position: (0; 3; -0.45).
  3. Ctrl+D → у копии Position: (0; 3; 0.45).
  4. Перетащи Floor со стенами в Project → Original Prefab → назови Corridor.

Размеры стен маленькие, потому что они вложены в пол: числа считаются от размера родителя.

Лайфхак: префаб комнаты с двумя выходами

  1. Внутри Floor продублируй Wall и назови Doorway.
  2. Rotation Y = 90, Scale (0.3; 5; 0.1).
  3. Сделай 4 таких куска стены с позициями:
КусокPosition
1(-0.45; 3; -0.3)
2(-0.45; 3; 0.3)
3(0.45; 3; 0.3)
4(0.45; 3; -0.3)

Перетащи Floor в Project → Original Prefab → назови Room.

ЛайфхакМеняй Scale родителя, и вся комната растянется целиком.

Прилепить объект к объекту

  1. Зажми V.
  2. Наведи на нужную вершину объекта.
  3. Тащи к вершине другого объекта, и они соединятся.

Добавить персонажа и поиграть

  1. Импортируй в проект пакет с персонажем First Person Controller (например, Mini First Person Controller из Asset Store).
  2. Перетащи префаб First Person Controller на место, где должен появиться игрок.
  3. У Main Camera сними галочку с компонента Audio Listener.
  4. Нажми Play вверху редактора.
  5. ПКМ по экрану игры — управление камерой. Esc — освободить курсор.
  6. Чтобы выйти из игры, снова нажми Play.

Двигаться: WASD. Клавиши бега, прыжка и приседания указаны в компонентах First Person Controller в Inspector.

Собрать WebGL-билд

  1. FileBuild Settings.
  2. Add Open Scenes — добавить свою сцену.
  3. Выбери WebGL. Если модуля нет, нажми Install with Unity Hub.
  4. Switch Platform → дождись.
  5. Player Settings... → Publishing Settings: Compression Format = Disabled, галочка Decompression Fallback.
  6. Закрой окно → Build.
  7. Создай новую папку с именем игры и выбери её. Не в папке Assets!
  8. Жди, сборка займёт время.

Тестирование прототипа

Тестирование — это проверка, совпадает ли то, что получилось, с тем, что ожидали. Пример: ожидали, что игрок допрыгнет до любой платформы, а на деле некоторые стоят слишком далеко.

  • Плейтестер называет сильные и слабые стороны.
  • Разработчик решает, что исправить.
Модуль 2 · Урок 1

Начало работы с ландшафтом

Планируем открытый уровень пузырьковой диаграммой и лепим рельеф объектом Terrain.

Правила левел-дизайна

  • Границы не дают выйти за край уровня: океан, высокие горы.
  • Ориентиры выделяются на фоне и показывают цель: вулкан среди одинаковых гор.
  • Путь к цели не должен быть прямым: пусть игрок ищет плот, чтобы переплыть реку.
  • Дай выбор: с возвышенности (плато, террасы) видно всю местность.

Пузырьковая диаграмма

  • Круги («пузыри») — локации. Размер круга показывает размер и высоту локации.
  • Стрелки — направление и тип дороги.
  • Учитывай механики персонажа: ходьба, бег, прыжки, приседания.
  • Не больше 5–7 локаций, и у каждой своя форма рельефа.

Создать Terrain

  1. GameObject3D ObjectTerrain.
  2. Отдали камеру: плоскость очень большая.

Компоненты: Transform (положение), Terrain (форма, цвет, размер и все инструменты), Terrain Collider (твёрдость, чтобы не проваливаться).

Инструменты компонента Terrain

Ряд кнопок вверху компонента Terrain в Inspector:

  • Paint Terrain — рельеф и текстуры (кисти).
  • Paint Trees — деревья.
  • Paint Details — трава и цветы.
  • Terrain Settings — настройки (шестерёнка).

Уменьшить ландшафт до удобного размера

  1. Компонент Terrain → Terrain Settings.
  2. Найди раздел Mesh Resolution.
  3. Terrain Width = 50, Terrain Length = 50, Terrain Height = 60.

Ширина, длина и максимальная высота. Для правдоподобия важны не настоящие размеры, а соотношение: гора должна быть намного больше персонажа.

Дать ландшафту толщину

  1. Paint Terrain → в списке кистей выбери Set Height.
  2. Height = 8.
  3. Нажми Flatten All. Весь ландшафт поднимется на 8 м.
ЗачемБез толщины нельзя сделать впадины, озёра и ущелья.

Горы и впадины

  1. Paint Terrain → Raise or Lower Terrain.
  2. Зажми ЛКМ над ландшафтом — рельеф растёт (горы, холмы).
  3. Shift+ЛКМ — рельеф опускается (впадины).
  • Brush Size — размер кисти, подбирай под площадь.
  • Opacity — сила кисти: меньше, значит мягче. Мягкой сглаживай и добавляй мелкие детали, жёсткой делай основной объём.
  • Кисти с мягкими краями дают плавный переход (холмы, склоны), с ровной формой — плато и террасы, острые — выступы и неровности.

Уступы (террасы) на горе

  1. Выбери Set Height.
  2. Наведи кисть на гору и нажми с Shift: высота этого места появится в поле Height.
  3. Округли число и уменьши его на высоту прыжка игрока.
  4. Рисуй кистью: получится ровная ступенька, на которую можно запрыгнуть.

Склон между уступами

  1. Узнай высоту самого высокого уступа (Shift в Set Height).
  2. Округли и отними 0.5. Впиши в Height.
  3. Кисть builtin_brush_3, размер 3, Opacity 1.
  4. Слегка проведи между двумя уступами.

Персонаж для проверки ландшафта

  1. Создай папку ThirdParty.
  2. WindowPackage Manager → My Assets.
  3. Найди Mini First Person Controller → Import.
  4. Перенеси импортированную папку в ThirdParty.
  5. У Main Camera выключи Audio Listener.
  6. Перетащи First Person Controller на место старта.

Проверь: игрок нигде не застревает, ориентиры видны со старта, через границы не пройти.

Модуль 2 · Урок 2

Детализация ландшафта

Собираем доску настроения, красим землю текстурами и добавляем воду, деревья и траву.

Визуальный стиль: 4 правила

  1. Связан с историей мира игры (лор).
  2. Подходит под сеттинг. Для ландшафта это ещё и биом: жаркий, холодный или умеренный климат.
  3. Передаёт настроение: тёплые и холодные, тёмные и светлые цвета.
  4. Помогает игроку ориентироваться: контрастный цвет цепляет взгляд и показывает, куда идти.

Доска настроения в Milanote

  1. Зарегистрируйся через почту Google.
  2. Перетащи Board из бокового меню, назови Landscape, открой двойным кликом.
  3. Картинки: Add Image → Upload your own (до 10.2 МБ, несколько с Shift). Они появятся справа в Unsorted.
  4. Колонки: перетащи Column, впиши заголовок, перетащи в неё картинки.
  5. Удалить лишнее: выдели и нажми Backspace.

Где брать картинки: Freepik и Unsplash. Ищи по слову, например «горы», или по категории Nature → Download free.

Палитра и экспорт доски

  1. Клик по пустому месту доски → три точки → Color → перетащи на доску.
  2. В меню цвета нажми Color и пипеткой возьми цвет с картинки.
  3. Сделай палитру из 5–6 цветов. Код цвета потом можно вставить в Unity в поле Hexadecimal.
  4. Сохранить доску: Export → PDF high quality.

Покрасить землю текстурой

  1. Скачай бесшовную текстуру земли, например Ground (Diffuse), и импортируй в Art/Textures через AssetsImport New Asset....
  2. Terrain → Paint Terrain → в списке кистей Paint Texture.
  3. Edit Terrain Layers... → Create Layer.
  4. В окне выбора дважды щёлкни по своей текстуре.
  5. В Assets появился ассет New Layer (это Terrain Layer). Переименуй его в Ground.
ВажноПервый слой покрывает весь ландшафт, поэтому для него бери бесшовную текстуру.

Добавить неровности: Normal Map

  1. Скачай карту нормалей к этой текстуре, например Ground (Normal), и импортируй.
  2. Выбери эту текстуру → Texture Type = Normal Map → Apply.
  3. Открой ассет слоя Ground.
  4. В поле Normal Map нажми Select и выбери Ground (Normal).

Поиграй с Normal Scale (сила неровностей) и Tiling Settings (повторение).

Нарисовать дорожки вторым слоем

  1. Скачай вторую текстуру, например землю для дорожек Ground Dirt (Diffuse).
  2. Edit Terrain Layers... → Create Layer → выбери текстуру.
  3. Переименуй новый слой в Path.
  4. Щёлкни по нему в списке Terrain Layers, выбери форму, размер и жёсткость кисти.
  5. Рисуй пути, по которым можно пройти.

Закрасил лишнее? Выбери первый (самый левый) слой и закрась поверх.

Добавить воду

  1. Импортируй из Asset Store пакет Aquas Lite (как в уроке М1У5) и положи в ThirdParty.
  2. Появилась папка _TerrainAutoUpgrade? Её можно удалить.
  3. AQUAS-Lite → Prefabs → перетащи воду на сцену.
  4. Подгони положение и размер под свою впадину.

Цвет: Main Color — основной, Deep Water Color — на глубине.

Посадить деревья

  1. Подготовь модель дерева (например, из Asset Store) и импортируй в проект.
  2. Terrain → Paint Trees.
  3. Edit Trees... → Add Tree.
  4. Нажми кружок, выбери модель → Add.
  5. Настрой Brush Size, плотность Tree Density и высоту Tree Height.
  6. Рисуй кистью по ландшафту.

Посадить траву и цветы

  1. Импортируй в проект текстуру травы.
  2. Terrain → Paint Details.
  3. Edit Details... → Add Grass Texture.
  4. Нажми кружок, выбери текстуру травы → Add.
  5. Настрой размер и жёсткость кисти и рисуй.

Настройка света

Три вида источников света, время суток, фонари и прожекторы.

Три источника света

ИсточникКак светит
Directional Light
направленный		как солнце: в одну сторону, равномерно на весь уровень
Spotlight
прожектор		в одну сторону, конусом
Point Light
точечный		во все стороны, но недалеко, как лампочка

Зачем нужен свет на уровне

  • Геймплей. В стелсе игрок прячется в тени, поэтому нужен сильный контраст света и тени.
  • Навигация. Яркий свет работает как маяк и ведёт игрока.
  • Атмосфера. Тёплый и яркий свет — радость и уют. Холодный и тусклый — тревога и опасность.

Три лайфхака светового дизайна

  1. Начинай с Directional Light. Это ключевой свет (key light), он задаёт тон всей сцене. Потом ставь акценты точечными светами и прожекторами — это заполняющий свет (fill light).
  2. Свет, который показывает важные места и путь, делай ярким и контрастным. Свет для атмосферы — мягче.
  3. Перед работой дополни доску настроения референсами: кадрами из фильмов, фото, других игр.

Главные настройки компонента Light

Они одинаковые у всех трёх источников:

  • Type — тип источника.
  • Color — оттенок света.
  • Mode — способ расчёта (Realtime или Baked).
  • Intensity — яркость.
  • Indirect Multiplier — яркость отражённого света.
  • Shadow Type — какие тени.
  • Range — дальность (у Point и Spot).

Свет — это компонент, его можно добавить к любому объекту. Объект будет освещать всё вокруг, но сам светиться не станет.

Поменять время суток

Выбери Directional Light и меняй Rotation X в Transform:

Rotation XВремя
0утро, солнце на горизонте
90полдень, солнце сверху
180закат
между 180 и 360ночь (270 — глубокая ночь)

Rotation Y меняет, с какой стороны светит солнце.

Точечный свет рядом с игроком

  1. GameObjectLightPoint Light.
  2. Поставь рядом с игроком (смотри на его координаты).
  3. Настрой Intensity, Color и Range.

Range — радиус сферы, внутри которой светит лампа. Например, 10 м.

Фонарь с лампой внутри

  1. Возьми модель фонаря в виде пакета (.unitypackage).
  2. AssetsImport PackageCustom Package... → выбери файл.
  3. Найди префаб фонаря в папке Prefabs пакета и поставь на сцену.
  4. В Hierarchy перетащи Point Light внутрь фонаря.
  5. Подвинь свет так, чтобы казалось, что светит лампа.
  6. Примени к префабу: Overrides → Apply All.
Иконки мешают?В окне Scene открой Gizmos и уменьши ползунок 3D Icons.

Прожектор у цели игрока

  1. GameObjectLightSpotlight.
  2. Настрой Range и Intensity.
  3. Выбери необычный цвет, чтобы было загадочно.
  4. Поверни прожектор (E) так, чтобы он светил на цель.
ЛайфхакНе получается поставить свет? Поставь в нужное место простой куб и скопируй его координаты.

Запечь свет

Запечённый свет (baked) рассчитывается заранее, а не каждую секунду игры, поэтому компьютеру легче.

  1. Выбери источник света.
  2. В компоненте Light поставь Mode = Baked.
  3. Повтори для всех источников.

Если после этого свет пропал, открой WindowRenderingLighting и нажми Generate Lighting.

Помощь

Если что-то не работает

Частые ситуации на уроках и что с ними делать.

Потерял объект на сцене

Выбери его в Hierarchy и нажми F.

Сделал что-то не то

Ctrl+Z отменяет последнее действие.

Изменения пропали после того, как выключил игру

Всё, что меняешь, пока нажата кнопка Play, не сохраняется. Сначала выйди из Play, потом меняй сцену.

Дубликат «не появился»

Он стоит ровно на месте оригинала. Сдвинь его клавишей W.

Пол пропадает, если смотреть снизу

Plane виден только сверху, так и должно быть.

После работы в проводнике пропали объекты или сцена

Файлы из Assets трогай только внутри Unity, в окне Project.

Экземпляр префаба встаёт криво

Скорее всего, группировал через Create Empty. Группируй через Create Empty Parent.

Голубая полоска слева от объекта

Изменения не попали в префаб: Overrides → Apply All.

Настройки материала серые и не меняются

Это Default Material, его нельзя менять. Создай свой материал.

Поменял цвет у одного объекта, а поменялся у всех

У них общий материал. Создай отдельный материал для этого объекта.

Текстура растянута или слишком мелкая

Настрой Tiling в материале (у Terrain Layer — Tiling Settings).

Поверхности мелькают при движении камеры

Две поверхности стоят в одном месте и спорят, какую рисовать. Чуть-чуть сдвинь один из объектов.

Прохожу сквозь объекты из Asset Store

У них нет коллайдера. Для прототипа это нормально, коллайдеры будут позже.

В консоли жёлтые треугольники

Это предупреждения. Они только советуют и работе проекта не мешают.

Пишет про два Audio Listener

У Main Camera сними галочку с Audio Listener: у персонажа есть своя камера.

Нет пакета в Package Manager

Проверь, что вошёл в аккаунт Unity и нажал Add To My Assets. Потом нажми стрелку обновления в списке My Assets.

Ошибка «…incompatibility between Color Space and current settings»

Player Settings → Other Settings: Color Space = Gamma, Lightmap Encoding = Normal Quality.

Нет платформы WebGL

В Build Settings нажми Install with Unity Hub.

Собранная игра не запускается в браузере

Player Settings → поставь галочку Decompression Fallback, удали папку со старым билдом и собери заново.

Не получается сделать впадину на Terrain

У ландшафта нет толщины: Set Height → Height 8 → Flatten All.

Кисть рисует не той текстурой

Щёлкни по нужному слою в списке Terrain Layers.

Сцена стала совсем тёмной

Проверь Rotation X у Directional Light: от 180 до 360 — ночь.
